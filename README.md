# Andy Sin's Personal Website

This is a responsive personal website built using the Hack4Impact Starter Pack
and restyled with a Frutiger Doric visual system: glassy cloud panels, aqua
water tones, lime accents, floating bubbles, and custom SVG artwork.
It introduces me, documents what I learned, highlights the site as my first
portfolio project, and includes a digital resume and contact form.

## Pages

- Home
- Blog
- Portfolio
- Resume
- Contact

## Built with

- Semantic HTML5
- CSS3 and Flexbox
- Git and GitHub Pages
- Custom accessible SVG artwork

## Publish

After creating a public repository named `<username>.github.io`, replace
